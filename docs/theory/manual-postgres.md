APT — это менеджер пакетов в Debian/Ubuntu. Он работает с репозиториями — специальными серверами, где хранятся тысячи программ. сохраняет в /var/lib/apt/lists/ все программы чтобы apt знал о всех пакетах
Репозиторий - Сервер, где хранятся пакеты (программы) для установки
PGDG (PostgreSQL Global Development Group) - Официальный репозиторий PostgreSQL, где доступны все версии БД
Кэш APT - Локальное хранилище информации о пакетах (в /var/lib/apt/lists/)
Update - Обновление списка пакетов (скачивает свежие версии из репозиториев)
Upgrade - Обновление уже установленных пакетов до новых версий
Install - Установка нового пакета
Purge - Полное удаление пакета вместе с конфигурационными файлами
