Go — компилируемый язык программирования от Google, используемый для создания бэкендов, микросервисов и CLI-утилит.

Бинарник (binary) — скомпилированный исполняемый файл, который можно запускать на сервере без установки Go.

Кросс-компиляция — сборка бинарника для другой операционной системы (например, на Windows собрать программу для Linux).

go mod — встроенная система управления зависимостями в Go.

go.mod — файл, в котором перечислены зависимости проекта и требуемая версия Go.

go.sum — файл с контрольными суммами зависимостей для проверки их целостности.

Зависимости (dependencies) — сторонние библиотеки, которые использует проект (например, gin, pq).

go mod download — команда, которая скачивает все зависимости из go.mod в локальный кэш.

go build — команда, которая компилирует исходный код в исполняемый бинарный файл.

GOOS — переменная окружения, указывающая целевую операционную систему при кросс-компиляции (например, linux).

GOARCH — переменная окружения, указывающая архитектуру процессора при кросс-компиляции (например, amd64).

SCP (Secure Copy Protocol) — протокол для безопасного копирования файлов между компьютерами по SSH.

scp -r — флаг для рекурсивного копирования целых папок со всем содержимым.

systemd — система инициализации и менеджер сервисов в Linux.

Сервис (service) — фоновый процесс, управляемый systemd.

Unit-файл — конфигурационный файл в systemd, описывающий сервис (расширение .service).

systemctl — команда для управления сервисами в systemd.

systemctl enable — команда, добавляющая сервис в автозапуск при старте системы.

systemctl start — команда для немедленного запуска сервиса.

systemctl stop — команда для остановки сервиса.

systemctl restart — команда для перезапуска сервиса.

systemctl status — команда для проверки текущего состояния сервиса (running, stopped, error).

systemctl daemon-reload — команда, которая перечитывает все unit-файлы после их создания или изменения.

journalctl — команда для просмотра логов systemd.

Переменная окружения — параметр, который передаётся процессу (например, порт сервера, пароль базы данных).

.env файл — текстовый файл для хранения переменных окружения (обычно не коммитится в Git).

EnvironmentFile — директива в systemd для загрузки переменных окружения из файла.

curl — команда для отправки HTTP-запросов из терминала.

JWT (JSON Web Token) — токен для авторизации, передаётся в заголовке Authorization при запросах к API.

HTTP-методы — типы запросов: GET (получить данные), POST (создать), PUT (обновить), DELETE (удалить).

404 page not found — HTTP-ошибка, означающая, что запрошенный URL не существует на сервере.

Authorization header required — ошибка API, означающая, что запрос требует передачи JWT-токена в заголовке.

connection refused — ошибка, означающая, что сервер не запущен или порт закрыт.
