hypervisor - это специальная программа, которая управляет одновременной работой нескольких виртуальных машин на одном физическом компьютере. Она распределяет аппаратные ресурсы (процессор, оперативную память, диск) между гостевыми операционными системами и изолирует их друг от друга.Гипервизор типа 1 (Bare-metal) устанавливается напрямую на железо без хостовой ОС. Он используется в дата-центрах и облаках — например, VMware ESXi или KVM. Гипервизор типа 2 (Hosted) — это программа внутри обычной ОС, как VMware Workstation или VirtualBox. Я в своём проекте использовала тип 2, так как работала на ноутбуке. Для production-серверов в компании, скорее всего, используется тип 1
Гостевая ОС - операционная система, установленная внутри виртуальной машины
Хост ОС - основная ОС, на которой установлен гипервизор
Bridged Network - VM получает IP-адрес из той же сети, что и хост
NAT Network - VM находится за внутренним маршрутизатором хоста
Host-Only Network - VM видит только хост и другие VM в этой сети. Полная изоляция, интернета нет. Используется для тестирования, когда не нужен выход в сеть.
Snapshot - Сохранение состояния VM в определённый момент времени
Thin Provisioning - Диск выделяется по мере заполнения. VM занимает на физическом диске столько, сколько реально используется, а не весь выделенный объём сразу. Экономит место.
Thick Provisioning - Весь выделенный диск занимается сразу. Быстрее работает, но требует больше места на хосте
vCPU - Виртуальный процессор, выделенный VM
Debian - Один из старейших дистрибутивов Linux, родитель Ubuntu
APT (Advanced Package Tool) - Менеджер пакетов в Debian/Ubuntu. Установка, обновление, удаление программ
Systemd - Система инициализации и менеджер сервисов. Управляет сервисами: запуск, остановка, автозапуск. Команда systemctl status ssh показывает, работает ли SSH-сервер
systemctl - Команда для управления systemd
journalctl - Просмотр логов systemd
SSH (Secure Shell) - Протокол защищённого удалённого доступа. Всё соединение шифруется
Пользователь root - Суперпользователь с полным доступом к системе
sudo - Выполнение команды с правами root
GRUB - Загрузчик Linux
Swap - Раздел на диске, используется как "медленная оперативная память". Когда RAM заканчивается, система начинает использовать swap
IP-адрес - Уникальный идентификатор устройства в сети
Порт - Номер, указывающий на конкретный сервис на устройстве
Localhost / 127.0.0.1 - Ссылка на текущий компьютер
DNS (Domain Name System) - Преобразует доменные имена в IP-адреса
TCP (Transmission Control Protocol) - Протокол с установкой соединения, гарантирует доставку
UDP (User Datagram Protocol) - Быстрый протокол без гарантии доставки
Reverse Proxy - Сервер, который принимает запросы извне и перенаправляет их внутренним сервисам. В моём проекте nginx слушает порт 80, а запросы на /api/ проксирует на Go-приложение, которое слушает порт 8080
HTTP - Протокол передачи гипертекста
HTTPS - HTTP поверх SSL/TLS (шифрование)
SSL/TLS - Протоколы шифрования для безопасной передачи данных. TLS — современная версия SSL. Обеспечивает шифрование, аутентификацию сервера, целостность данных.
Как проверить, что сервис слушает порт? - sudo netstat -tlnp или ss -tlnp
Ручное развертывание (Manual Deployment) - Процесс установки и настройки приложения на сервере без автоматизации
Production-среда - Окружение, где работает реальное приложение, доступное пользователям
Staging-среда - Окружение, максимально приближенное к production, для тестирования перед релизом
Dev-среда (Development) - Окружение на ноутбуке разработчика
PostgreSQL - Реляционная база данных с открытым исходным кодом
Реляционная БД (RDBMS) - Данные хранятся в таблицах со связями между ними
Миграции - Управление изменениями схемы БД в коде
ACID - Atomicity, Consistency, Isolation, Durability — свойства транзакций
