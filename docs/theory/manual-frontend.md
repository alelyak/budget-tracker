nginx — веб-сервер и reverse proxy, который принимает HTTP-запросы из интернета и перенаправляет их к бэкенду (Go-приложению) или отдаёт статические файлы фронтенда.

Reverse proxy — сервер, который принимает запросы от клиентов и перенаправляет их к другим внутренним серверам (например, к Go-приложению на порту 8080).

Статические файлы — файлы, которые не меняются при каждом запросе: HTML, CSS, JavaScript, изображения. nginx отдаёт их напрямую без вызова бэкенда.

root (в nginx) — директива, указывающая путь к папке, где лежат статические файлы сайта (в нашем случае dist).

location (в nginx) — директива, определяющая, как обрабатывать запросы к разным URL-путям (например, /api/ — проксировать, / — отдавать статику).

proxy_pass — директива nginx, которая перенаправляет входящие запросы на другой внутренний адрес (например, http://localhost:8080).

ERR_CONNECTION_REFUSED — ошибка браузера, означающая, что соединение с сервером не установлено: сервер не запущен, порт закрыт или браузер стучится не по тому адресу.

baseURL — базовый адрес, который используется в axios (или других HTTP-клиентах) для формирования полного URL запроса.

axios — популярная JavaScript-библиотека для отправки HTTP-запросов из браузера (используется в React-приложениях).

CORS (Cross-Origin Resource Sharing) — механизм безопасности браузера, разрешающий или запрещающий запросы с одного домена к API на другом домене.

npm run build — команда, которая собирает React-приложение в статические файлы (HTML, CSS, JS) в папку dist или build.

vite — быстрый сборщик для фронтенд-проектов (альтернатива webpack), который мы использовали для сборки React-приложения.

dist — стандартное название папки, куда Vite складывает собранные файлы фронтенда (от англ. distribution — дистрибутив).

Permission denied (EACCES) — ошибка прав доступа, возникающая, когда пользователь пытается выполнить операцию с файлом или папкой, на которые у него нет прав.

sudo rm -rf — команда для принудительного рекурсивного удаления файлов/папок с правами суперпользователя (нужно быть осторожным).

sudo chown -R — команда для рекурсивной смены владельца файлов/папок.

sudo chmod — команда для изменения прав доступа к файлам/папкам (например, 755 — чтение и выполнение для всех, запись только для владельца).

www-data — системный пользователь в Debian/Ubuntu, от имени которого по умолчанию работает веб-сервер nginx.

HTTP-код 500 (Internal Server Error) — ошибка сервера, означающая, что сервер не смог обработать запрос (часто из-за проблем с правами или конфигурацией).

systemctl status — команда для проверки состояния systemd-сервиса (running, stopped, failed).

sudo systemctl restart nginx — команда для перезапуска веб-сервера nginx (применяется после изменения конфигурации).
